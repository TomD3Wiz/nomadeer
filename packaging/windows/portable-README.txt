Nomadeer @VERSION@ - portable edition for Windows
==================================================

Nomadeer is a wormhole companion for EVE Online: it maps your chain, follows
your characters and reads the killboard for the system you have selected.

Which one to run
----------------

  Nomadeer.exe              Optimized edition for processors with AVX2 (most
                            PCs from 2015 onwards). Umbra briefings run two to
                            three times faster.

  Nomadeer-compatible.exe   Compatible edition for older processors. Use this
                            one if Nomadeer.exe says your processor is not
                            supported, or does not start.

Your saved data
---------------

Characters, chains and Umbra are saved in the "data" folder next to these
files, so the whole folder can live on a USB stick or move to another PC.
The "portable" file tells Nomadeer to save here. Once the "data" folder holds
your saved data, Nomadeer keeps using it even without that file.

To switch to the installed version's location, %LOCALAPPDATA%\Nomadeer, move
everything inside the "data" folder there and delete both the "data" folder
and the "portable" file.

To update, replace the .exe files and keep the "data" folder.
